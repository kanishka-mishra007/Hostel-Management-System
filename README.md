1. Introduction
The Hostel Management System (HMS) is a Java-based desktop application developed to simplify and manage hostel student records efficiently. The system provides an easy-to-use graphical user interface (GUI) through which an authorized administrator can log in and perform various student management operations.
It allows the administrator to add new student details, view existing records, update student information, and manage student data systematically. The application uses Java Swing for the graphical interface and MySQL database for storing and managing student information.
The main objective of this project is to reduce manual paperwork, save time, improve data accuracy, and make hostel student record management easier and more organized.

2. Key Features
1. Admin Login: Secure login system for authorized administrators.
2. Dashboard: Centralized dashboard for accessing different hostel management operations.
3. Add Student: Add new student details such as Student ID, Name, Father's Name, Gender, DOB, Phone, Email, Course, Year, and Room Number.
4. View Student: Display all registered student records in a structured table.
5. Edit Student: Update existing student information whenever required.
6. Student ID Management: Supports alphanumeric student IDs, such as STU001.
7. MySQL Database: Stores and manages student records systematically.
8. User-Friendly Interface: Simple and attractive GUI for easy navigation.
